# SKIZEN Website Prompt

Create a premium, clean, modern, corporate-style website for SKIZEN, a marketing and technology company.

The website should feel luxurious, highly professional, trustworthy, and built for serious businesses. It should combine the clean minimalism of Swiss design with the premium visual quality of a modern digital agency.

The design should be white-themed with strong typography, lots of whitespace, structured grids, premium cards, subtle shadows, clean dividers, smooth interactions, and elegant animations.

Avoid clutter.
Avoid overly playful visuals.
Keep everything neat, balanced, sharp, and premium.

The website should look like a mix of:

* Stripe
* Linear
* Apple
* Notion
* Framer
* Vercel
* Premium Swiss-designed agency websites

* Charcoal

Usage Rules:

* Use white as the dominant background color.
* Use #1d1d1d for headings, premium sections, footer, navbar, and important text.
* Use #f56702 only for buttons, highlights, hover states, active navigation, icons, gradients, links, separators, and CTA sections.
* Keep the accent color elegant and minimal.
* Use subtle gradients combining white, light gray, and soft orange tones.
